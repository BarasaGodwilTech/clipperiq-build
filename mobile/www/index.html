Connect to your server

ClipperIQ Studio cuts your videos on a ClipperIQ server (your computer or a hosted server). Enter its address once and this app remembers it.

Where do I find the address?

On a computer running ClipperIQ Studio on the same Wi-Fi, use that computer's local address, for example 192.168.1.20:3000 (set HOST=0.0.0.0 in its .env file so phones can reach it). For a hosted server use its https address. If the server has a password, your phone will ask for it.
